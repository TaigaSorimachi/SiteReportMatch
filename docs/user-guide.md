### 2.2 会社管理

**サイドバー → 会社管理**

#### 会社一覧

```
┌──────────────────────────────────────────────────────┐
│ 会社一覧                              [新規作成]      │
│                                                      │
│ ┌────────────┬────────┬────────┬────────┬──────────┐ │

│                                                      │
│                        < 1 / 1 >                     │
```

**操作手順:**

1. **会社を新規登録する**
   - 右上の「新規作成」ボタンをクリック
   - モーダルで会社名（必須）、種別（必須）、代表者、電話番号、メール、住所を入力
   - 「作成」ボタンで保存

2. **会社情報を編集する**
   - テーブルの行をクリックして詳細画面に遷移
   - 各項目を編集し「保存」ボタンで更新

   - 「追加」ボタンで作成
   - ※ 1会社につきオーナーは1名のみ

   - 「作成」ボタンで保存

2. **ユーザーを検索する**
   - 検索欄に名前またはメールを入力してフィルタリング

3. **ユーザー情報を編集する**
   - テーブルの行をクリックして編集画面に遷移

```

│ │ 案件名      │ 現場名  │ステータス│ 契約金額   │ 工期   │ │
```

**操作手順:**

1. **案件を新規作成する**
   - 「新規作成」ボタンをクリック
   - 案件名（必須）、案件コード、説明、ステータス、現場名、住所、工期（開始/終了）、契約金額、見積金額、ジオフェンス半径を入力
   - 「作成」ボタンで保存

2. **案件をフィルタリングする**
   - ステータスドロップダウンで「計画中」「進行中」「完了」等を選択

3. **案件を編集する**
   - テーブルの行をクリックして編集画面に遷移

#### まとめ入力（バッチ入力）

1. 「まとめ入力」をタップ
2. 案件を選択（ドロップダウン）
3. 作業日を入力
4. 出勤・退勤時間を入力
5. 休憩時間を入力（分）
6. 作業内容を記入（必須）
7. 進捗率を入力（0-100%）
8. 天候を選択
9. 「確認」ボタンで確認画面に遷移
10. 確認後に送信

```
└─────────────────────────────────────┘
```

#### 募集を作成する

1. 「募集する」をタップ
2. 契約種別を選択（日当制 / 請負）
3. 基本情報を入力（現場名、都道府県、市区町村、工種、期間、人数、単価）
4. 必要に応じて物件情報、条件、スキル要件を展開して入力
5. 「公開する」ボタンで投稿

#### 仕事を探す

1. 「仕事を探す」をタップ
2. フィルター（都道府県、工種、契約種別、開始日）で絞り込み
3. 「検索」ボタンで検索
4. 求人カードをタップして詳細表示
5. 詳細画面から応募が可能

#### 人材を公開する

1. 「人材を公開」をタップ
2. タイトル、工種、契約種別、希望単価を入力
3. 対応可能期間とエリアを設定
4. スキルレベルと経験年数を入力
5. 「公開する」ボタンで投稿

## 4. 作業者（worker）操作ガイド

作業者は **フロントエンド（LIFF）** を使用します。日報と出退勤機能のみ利用可能です。

### 4.1 ボトムナビゲーション

```
┌─────────────────────────────────────┐
│            （画面コンテンツ）          │
│                                     │
├──────────┬──────────┬──────────────┤
│    📋    │    ⏰    │     ⚙️       │
│   日報    │  出退勤   │    設定       │
└──────────┴──────────┴──────────────┘
```

**マッチング・レポートタブは表示されません。**

### 4.2 日報管理

オーナーと同じ操作ですが、**承認・差し戻し機能はありません**。
日報の作成と履歴の閲覧のみ可能です。

**操作手順:**

1. 「まとめ入力」または「リアルタイム」で日報を作成
2. 「日報履歴」で過去の日報を確認
3. 日報詳細で提出状態を確認

### 4.3 出退勤

オーナーと同じ操作です。

1. 案件を選択して「出勤する」
2. タイマーが自動計測
3. 休憩の開始/終了を記録
4. 「退勤する」で退勤処理
